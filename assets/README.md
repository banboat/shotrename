# Embedded data

## cities.tsv

- Source: GeoNames `cities15000` dump, <https://download.geonames.org/export/dump/>.
- Retrieved: 2026-11-21.
- License: Creative Commons Attribution 4.0 (CC BY 4.0), <https://creativecommons.org/licenses/by/4.0/>.
- Modifications: kept `latitude`, `longitude`, `name`, a Chinese alias, `country` and `population`; sorted by population; generated by [`tools/build_gazetteer.py`](../tools/build_gazetteer.py).

The Chinese alias prefers a CJK token ending in `市` from the source `alternatenames` column, with the trailing character removed.

To rebuild:

```bash
curl -O https://download.geonames.org/export/dump/cities15000.zip
unzip cities15000.zip
python3 tools/build_gazetteer.py cities15000.txt
```
